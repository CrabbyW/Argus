## Ahoj 👋

Vývojář na volné noze — full-stack, hlavně **.NET + React/TypeScript**. Dělám interní systémy
na zakázku: od návrhu datového modelu přes API až po UI, které lidem nepřekáží.

### Co jsem postavil

**Argus** — inventář instalací. Jediná autoritativní odpověď na otázku *„kde je tahle aplikace
vlastně nainstalovaná?“*: pro každou instalaci která **aplikace**, v jakém **stage**, na jakém
**stroji**, pod jakým **DNS jménem** a v jaké **cestě**, na jaké architektuře a v jakém období.
Nahrazuje znalosti v hlavách, tabulky v Excelu a klikání po IIS konzolích jedním dotazovatelným
systémem záznamu. Historie zůstává — vyřazení je soft delete plus `ValidToDate`, takže *„co tu
běželo minulý kvartál?“* je pořád zodpovězitelná otázka.
Záměrně **není** deployovací ani monitorovací nástroj: Argus realitu zaznamenává, nemění ji.

*NX monorepo (pnpm) · .NET 10 + EF Core (code-first) + MSSQL · React 19 + TypeScript + Fluent UI
(Vite) · JWT auth.*
